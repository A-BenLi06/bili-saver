# 本地爬山测试与改进

把最近一次通过验证的提交当作当前基线。每轮只试一个可回退的补丁，并在测量前写明主要指标、保护指标和通过线。候选先按影响、把握、成本排序。正确性和归档数据完整性是硬门槛，性能换不来例外。

| 首批顺序 | 候选 | 影响 | 把握 | 成本 |
| --- | --- | --- | --- | --- |
| 1 | 按日志序号定位新增行，减少空轮询扫描 | 高频日志轮询 | 高 | 低 |
| 2 | 按需一次性复制快照，减少历史分页的分配 | 首屏及堆积日志读取 | 高 | 低 |
| 3 | 缓冲小块归档输出的比较读取 | 可能减少文件读取调用 | 中 | 中，需大块写入和缩短输出的对照 |

1. 从最近一次通过的本地提交创建干净的临时 worktree。在实验分支只改一个行为。两侧保留同一基准用例和输入，且测量时不要编辑。正确性修复用可复现的失败用例作为主要证据，先证实旧实现失败，再验证新实现和所有保护项。下面的脚本用于具备 Go 微基准的性能候选。
2. 对基线和候选运行相关包测试、构建、vet、完整内部测试和 diff 检查，再对候选跑相关包的 race 检测。脚本在单 CPU 配置下串行测量，交替先跑基线和候选。默认 5 对，每个场景每次 200 ms。
3. 主要场景的延迟中位数须至少降低 10%，且过半配对各自达到该门槛。其他场景延迟中位数最多上升 15%。所有场景的每次分配字节数、次数中位数都不得上升。结果只代表指定合成负载，不等于线上端到端延迟。
4. 比较原始日志、检查 diff，确认通过后仅在本地提交，该提交成为下一轮基线。拒绝时先保存候选 diff，再在独立实验分支只恢复本轮文件。基线失败、缺少样本或环境异常时结论为 inconclusive，排除原因后才重测。不要为了通过调整门槛，也不要不断重复直到出现有利结果。
5. 每轮从剩余候选中重新排序。默认一批最多 2 个候选。连续 2 个拒绝、没有可信候选或基线不再可靠时停止，记录证据并重新选目标。这是有界的本地流程，由维护者提供补丁并复核，脚本负责量化判定。

从实验分支根目录运行。将 `/tmp/bili-base` 换成独立的临时路径，确保当前 Go 工具链与 `go.mod` 一致。输出目录必须是新目录，建议放在实验工作区外，便于保存和对照。

```bash
git worktree add --detach /tmp/bili-base <最近通过的SHA>
python3 scripts/hill_climb.py \
  --base /tmp/bili-base --candidate . --out /tmp/bili-round-01 \
  --package ./internal/logging \
  --cases RingSnapshot/CaughtUp RingSnapshot/Recent RingSnapshot/Backlog \
  --primary RingSnapshot/CaughtUp
```

日志场景使用 4,000 条合成记录。CaughtUp 表示没有新日志，Recent 表示读取 8 行，Backlog 表示读取首页上限 1,000 行。测试使用临时数据和本地 mock。退出码 0 表示通过，1 表示拒绝，2 表示没有可靠结论。输出包含 `decision.json`、每次基准输出及各门槛日志。

## 首批结果

Linux amd64，Go 1.27.1。每轮使用 5 对采样。下表记录主要场景及当轮保护指标，延迟为中位数。

| 轮次 | 基线 | 保留提交 | 主要场景 | 保护指标 |
| --- | --- | --- | --- | --- |
| 1 按序号定位 | `236452b` | `92a0fcf` | CaughtUp 3,652 → 13.10 ns/op（−99.6%） | Recent −93.0%，Backlog −6.1%，分配无增加 |
| 2 一次性复制 | `92a0fcf` | `fe9acd9` | Backlog 23,705 → 7,754 ns/op（−67.3%），11 → 1 次分配，89,760 → 40,960 B/op | Recent −59.8%，CaughtUp 13.21 → 14.45 ns/op（+9.4%，低于 15% 上限），分配无增加 |

两轮候选的针对性测试、全量内部测试、构建、vet、日志包 race 检测和 diff 检查均通过。新增回归测试覆盖缓冲淘汰后的序号、分页边界和副本隔离。

第一次采集因基准筛选漏掉 `Benchmark` 前缀而无结论。修复筛选后用原门槛重新采样。独立 Cloud 工作区保留了三次运行的日志、决策 JSON 和候选补丁，目录为 `/workspace/bili-hill-results/`。
