Archive guide

Configure your archive, export original records, or move the complete archive.

1. Configure

Current archive:

  1. Change your administrator password. Initial credentials are in the archive's private credentials.json file.
  2. Sign in to Bilibili to enable account-dependent collection. Guest collection can be incomplete.
  3. Choose collection intervals and limits. Partial scans do not confirm disappearance.
  4. Choose download quality and concurrency. Install ffmpeg for media merging.
  5. Configure output libraries. Keep their roots separate from original archive directories.

Settings marked for restart take effect on the next startup. Keep the startup configuration file and archive directory together when planning backups.

2. Export core records

The ZIP contains versioned NDJSON records for videos, historical parts, comments, danmaku, statistics, original subtitle indexes, tags and official conclusions. Disappeared records are retained.

It excludes accounts, credentials, settings, plugins and derived data. Media bytes, raw response files and subtitle files require a complete private backup in the next step. This record export cannot restore an archive by itself.

Comments and author identifiers can contain personal information. Review the exported data before sharing it.

3. Migrate the complete archive

Stop the source service first. Run these commands on its machine using PowerShell. Choose new, empty destination paths outside the source archive. Keep the source until verification succeeds.

Enter both destination paths to generate commands. Files are not moved by this page.

    For another computer, transfer the entire private backup directory, including manifest.json, before running restore there. Also install a compatible bili-saver binary and ffmpeg.

    After restore, review the generated config.yaml: listener, ffmpeg, media output and hosted sites. Plugins and hosted sites are disabled for review. A backup without a startup snapshot also defaults automatic downloads and media output to disabled. Run check before starting; then confirm videos, parts, settings and login. Retain the source and backup until satisfied.

    Private backups include credentials, cookies and account state. Keep them private; use the core export or content catalog for sharing.
